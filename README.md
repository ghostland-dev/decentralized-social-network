# Decentralized Social Network

Social network client built on public-key identities.

## Features

- Feed, posts and messaging
- Profiles addressed by public key
- Notifications and settings

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)

## Getting Started

```bash
git clone https://github.com/ghostland-dev/decentralized-social-network.git
cd decentralized-social-network
npm install
npm run dev
```

Other scripts:

- `npm run build`: next build
- `npm run lint`: eslint .
